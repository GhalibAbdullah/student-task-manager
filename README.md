# Student Task Manager

## Project Description

Student Task Manager is a simple web application created to demonstrate practical Git and GitHub workflows. The application allows users to create, display, search, complete, and delete student tasks.

## Team Members

This assignment was completed individually with T.A. approval.

## Features

- Add new tasks
- Add task descriptions
- Display tasks
- Search tasks by title
- Mark tasks as completed
- Delete tasks
- Responsive user interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Git Workflow

The project was developed using a feature-branch workflow. Individual features were developed on separate branches and integrated into the main branch through Pull Requests.

## Branches

The following branches were used during development:

- main
- feature/task-form
- feature/task-style
- feature/task-search
- conflict-version-a
- conflict-version-b

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional dependencies are required.
